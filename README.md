# Unmapped

A pocket roguelike RPG about wandering off the edge of an unfinished map. Single self-contained `index.html`, built for one-thumb play on a phone.

Play: https://7r9cv474hh-a11y.github.io/unmapped/

- `src/` holds the source (data, audio, art, game logic, UI, bot). `./build.sh` inlines everything into `index.html`.
- `tests/test.mjs` is a headless touch test at 390x844. `tests/sim.mjs` is the balance simulator.
- Fonts: Caveat Brush and Patrick Hand (SIL Open Font License), subset and embedded.
